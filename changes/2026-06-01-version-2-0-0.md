# Truthmark v2 workspace refactor

Previous version: 1.6.1
New version: 2.0.0
Diff basis: release/1.6.1..HEAD plus working tree
Version action: major
SemVer rationale: Version 2 establishes a workspace-scoped repository config and a unified Truthmark workspace.

Release payload:
- Use a `version: 2` `truthmark.workspace` config model.
- Store Truthmark-owned routes, truth docs, templates, and generated Portal output under the configured workspace, rooted at `docs/truthmark/` by default.
- Keep project-owned `docs/ai`, `docs/architecture`, and `docs/standards` outside the Truthmark workspace.
- Render host-native workflow surfaces, managed instruction blocks, routing, and README examples from the workspace model.

User-facing release text:
- Truthmark 2.0.0 provides workspace-scoped repository configuration. Run `truthmark init` to create or refresh the workspace and generated workflows.
