# Version 2.3.1

Previous version: 2.3.0
New version: 2.3.1
Diff basis: release/2.3.0..HEAD plus working tree
Version action: patch
SemVer rationale: This release fixes managed instruction installation for repositories that use symlinks without changing the config schema or command surface.

Release payload:
- Follow mechanically safe final symlinks for managed instruction files while leaving repository-owned target semantics alone.
- Install Claude Code's compact workflow block as an unscoped `.claude/rules/truthmark.md` rule and migrate the former `CLAUDE.md` block.
- Prevent inactive aliases from removing an active generated target and reject external or Git-administrative alias targets.

User-facing release text:
- Truthmark now works with common shared-instruction symlink setups, and Claude Code receives its workflow through a project rule instead of `CLAUDE.md` injection.

- `npm run release:check` passed: lint, format check, typecheck, 431 tests, build, 4 package-integrity tests, and production audit with 0 vulnerabilities.
- Repeated dogfood init was idempotent, and `truthmark check --json` reported no diagnostics after the Claude rule migration.
